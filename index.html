OWASP Build

How this portfolio was rebuilt with OWASP-aligned principles

Attack surface reduced

The exposed live chat flow, public third-party form key, and dynamic remote script loading were removed.

Strict browser policy

A restrictive Content Security Policy blocks external scripts, frames, object embeds, and form submission.

Safer client code

All interaction logic lives in a local script file and uses text-safe DOM patterns instead of HTML injection.

Third-party risk reduced

External font dependencies were removed so the page can render from local assets only.

Applied principles

  • Secure by default page behavior with no open form handlers or live messaging endpoints.
  • Minimized dependencies and client-side complexity.
  • Defense in depth through CSP, referrer policy, safe link attributes, and no inline script execution.
  • Fail-safe contact model using direct email and profile links instead of processing visitor input in-browser.
