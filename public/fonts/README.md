# Self-hosted Geist fonts

Geist Latin and Geist Mono Latin variable WOFF2 fonts are copied from the installed Next.js 16.2.12 package (`next/dist/next-devtools/server/font/`). They are served locally with `font-display: swap`; the primary font is preloaded in the root layout.

Upstream: https://github.com/vercel/geist-font
